# Hardikjagariya_2 – Personal Portfolio Website

## Project Title
Personal Portfolio Website

## Project Description
This project is a modern and responsive personal portfolio website developed using HTML, CSS, and JavaScript. It showcases personal information, technical skills, projects, certificates, educational background, and contact details in a professional and user-friendly interface.

The website is designed to provide visitors with an overview of the developer's profile while maintaining responsiveness across different devices.
